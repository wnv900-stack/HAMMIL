# HAMMIL

منصة أولية قابلة للتشغيل لمعاينة روابط الوسائط والتوجيه إلى خيارات الوصول والتنزيل المسموح بها.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل محلياً
```bash
npm install
cp .env.example .env
npm start
```
افتح `http://localhost:3000`.

## ما الذي يعمل في هذه النسخة؟
- واجهة عربية متجاوبة بالأسود والأخضر.
- API لفحص الرابط والتعرف على عدد من المنصات.
- معاينة YouTube عبر نطاق التضمين الرسمي.
- تشغيل روابط ملفات الوسائط المباشرة التي تنتهي بامتداد معروف، مع إظهار رابط المصدر.
- فتح المصدر الأصلي للمنصات الأخرى مع توضيح حدود المعاينة والتنزيل.

## حدود التكامل والتنزيل
هذه النسخة **لا تستخرج ملفات الفيديو من صفحات TikTok أو Instagram أو Snapchat أو YouTube ولا تتجاوز تسجيل الدخول أو DRM أو إعدادات الخصوصية**. التعرف على المنصة لا يعني أن التنزيل متاح.

لإضافة تنزيلات حقيقية لكل منصة، يجب تنفيذ تكامل منفصل باستخدام واجهاتها الرسمية أو آليات التصدير/التنزيل التي تسمح بها، مع OAuth عند الحاجة، ومراجعة شروط المنصة وحقوق المحتوى. لا تطلب كلمات مرور المستخدمين ولا تخزن ملفاتهم دون موافقة واضحة.

## النشر
يمكن نشر المشروع على Render أو Railway أو VPS يدعم Node.js:
1. ارفع ملفات المشروع إلى مستودع Git.
2. أنشئ Web Service من المستودع.
3. Build command: `npm install`
4. Start command: `npm start`
5. اربط نطاقك عبر إعدادات الاستضافة وفعّل HTTPS.

## متغيرات البيئة
- `PORT`: المنفذ (تحدده منصة الاستضافة غالباً).
- `NODE_ENV`: استخدم `production` عند النشر.
- `MAX_LINK_LENGTH`: أقصى طول للرابط.

## نقاط مطلوبة قبل الإطلاق العام
- إضافة سياسة خصوصية وشروط استخدام وبريد دعم.
- مراجعة قانونية وشروط كل منصة.
- اختبارات أمنية ومعدل طلبات مناسب.
- مراقبة الأخطاء وسجلات لا تحتوي على روابط خاصة أو رموز وصول.
- إضافة تكاملات OAuth الرسمية التي تحتاجها المنصات.
